# Lotto Lab Mobile

App Android per analisi statistica delle estrazioni del Lotto.

Funzioni:
- scelta ruota
- inserimento manuale estrazioni
- import CSV
- frequenze e ritardatari
- generazione cinquine statistiche
- storico combinazioni

Nota: le estrazioni sono casuali; le statistiche non garantiscono risultati.

Per generare l'APK: GitHub > Actions > Build Android APK > Run workflow.
